# نظام رواسي عدن للهندسة والمقاولات (Rawasi Aden System)
### النظام المحاسبي والإداري المتكامل - إدارة المشاريع والمحاسبة والمالية

نظام سحابي ومحلي متكامل لإدارة شركات المقاولات والهندسة المدنية، مصمم ومطور خصيصاً لشركة **رواسي عدن للهندسة والمقاولات** وفق أعلى المعايير الفنية والمالية وبنية برمجية قوية وواجهات مستخدم تفاعلية فاخرة (Dark Navy & Gold Luxury Theme).

---

## 🌟 مميزات النظام

1. **لوحة تحكم حية (Live Dashboard & KPIs)**:
   - متابعة المؤشرات المالية والتشغيلية الـ 8 الرئيسية: (إجمالي الدخل، إجمالي المصروفات، صافي الأرباح، رصيد الصندوق، مستحقات العملاء، مستحقات الموردين، المشاريع النشطة، إجمالي المشاريع).
   - رسم بياني دائري لتوزيع المصروفات حسب النوع (مواد، عمالة، معدات، نقل، إدارية، أخرى).
   - رسم بياني لمسار الإيرادات والمصروفات خلال 6 أشهر.
   - جدول العمليات المالية الحديثة.
2. **إدارة المشاريع (Projects Management)**:
   - تتبع تكاليف العقود، التكاليف التقديرية والفعلية ونسب الإنجاز التراكمية.
   - قياس الربح المتوقع والربح الفعلي لكل مشروع.
   - ربط آلي للمصروفات وأذونات صرف المواد بتكلفة المشروع الفعلية.
3. **المحاسبة العامة والقيود والسندات (Accounting & Vouchers)**:
   - تسجيل سندات القبض للعملاء وتحديث الذمم المدينة آلياً.
   - تسجيل سندات الصرف للموردين ومصروفات المشاريع وتحديث حركة الصندوق.
   - قيد محاسبي تلقائي لكل حركة مالية.
   - طباعة سندات القبض والصرف الرسمية بضغطة زر مع ترويسة الشركة والختم الرسمي.
4. **المشتريات والمخزون (Purchases & Inventory)**:
   - سجل الأصناف ومواد البناء، الكميات المتوفرة، والحدود الدنيا وتنبيهات النواقص.
   - أذونات صرف المواد للمشاريع وأثرها المباشر على المخزون وتكلفة المشروع.
5. **النثريات والعهد الميدانية (Petty Cash & Custodies)**:
   - تسجيل ومتابعة عهد المشرفين والمهندسين وتصفيتها وحساب المتبقي فورياً.
6. **الصندوق والبنك (Cash & Bank Movements)**:
   - كشف تفصيلي لحركة الصندوق (رصيد سابق، إيرادات نقدية، مصروفات، سحوبات، رصيد حالي).
7. **التقارير المالية وتصدير Excel (Reports & Export)**:
   - تقرير الأرباح والخسائر التفاعلي لفترات زمنية مخصصة.
   - كشف حساب تفصيلي للعملاء والموردين.
   - تصدير التقارير إلى ملفات Excel تدعم اللغة العربية (UTF-8).
8. **الأمان والنسخ الاحتياطي (Security & Backup)**:
   - إدارة المستخدمين والصلاحيات (المدير، المحاسب، مدير المشاريع، أمين المخزن).
   - تنزيل نسخة احتياطية من قاعدة البيانات بنقرة واحدة.

## 🚀 طريقة التشغيل السريعة

### 1. تثبيت التبعيات:
```bash
npm install
```

### 2. بذر أو إعادة تعيين البيانات التجريبية:
```bash
npm run seed
```

### 3. تشغيل النظام:
```bash
npm start
```
سيعمل الخادم تلقائياً على الرابط:
**http://localhost:5500**
