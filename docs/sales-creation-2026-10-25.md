# إنشاء مستندات المبيعات

- من القائمة «المبيعات ← إنشاء عرض سعر»: اختر المشروع، ثم أدخل عنوان العرض والتاريخ والقيمة والخصم والشروط واحفظ. يظهر العرض في «عروض الأسعار» للمشروع المحدد.
- من «المبيعات ← إنشاء فاتورة»: اختر العميل ثم المشروع والعقد إن وجد، وأدخل التاريخ والمبالغ والاستقطاعات والملاحظات، ثم اضغط «حفظ الفاتورة كمسودة». يمكن مراجعتها من سجل العميل ومتابعة اعتمادها وترحيلها وفق صلاحيات النظام.
- إنشاء الفاتورة يستخدم نوع المستند «فاتورة»، ويحفظها كمسودة دون قيد مرحل. مسار إصدار المستخلصات الحالي يحتفظ بسلوكه.
- يتطلب عرض السعر صلاحية إنشاء/تعديل المشاريع مع صلاحية عرضها، والفاتورة صلاحية إنشاء الفواتير والوصول إلى سجل العملاء.

التحقق: اختبار API على قاعدة مصطنعة لحفظ عرض بقيمة 450 وربطه بالمشروع، وحفظ فاتورة بقيمة 400 للعميل والمشروع بنوع فاتورة وحالة مسودة دون زيادة القيود. اختبار Edge يفتح النموذجين من القائمة ويتحقق من المشروع المختار ونوع الفاتورة وحالتها عند الإرسال. تشمل الفحوصات اختبارات التنقل والصلاحيات القائمة.
