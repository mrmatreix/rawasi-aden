- اختبار الاستعادة يعيد القاعدة والمشاريع والمرفقات إلى مجلد جديد، ويبدأ نسخة staging ثم production ويقرأ التقارير والمستندات.

- لا توجد شهادة بتغطية كل API أو سيناريوهات HR/المخزون/العقود، ولم يُنفذ Redeploy أو Rollback سحابي.

## قاعدة البيانات والقيود المتبقية

- SQLite يستخدم WAL وbusy_timeout وتسلسلاً للكتابة داخل العملية؛ التشغيل المعتمد نسخة واحدة فقط. المعاملات المتداخلة غير مشمولة بشهادة الاختبار.
- مقارنة المخططين في SCHEMA_COMPARISON_AR.md بنيوية؛ لا تثبت تشغيل MySQL أو توافق نوع البيانات والاستعلامات أو الأداء.
- لم تُعدّل قاعدة الإنتاج أو تُنقل إلى MySQL، ولم تُستبدل بقاعدة العمل المحلية.
- إزالة ملفات البيانات والإعدادات من تتبع Git لا تمحو تاريخ Git. يلزم تدوير الأسرار ومراجعة التاريخ وصلاحيات المستودع.
- المصادقة الحالية تستخدم PIN وOTP حسب الميزة؛ إرسال SMS/البريد وTOTP والاسترداد الآمن للحسابات تحتاج مراجعة مستقلة.
- صفحة Variables تحتوي قيماً لا تطابق environment الذي تعلنه واجهة النشر؛ لا تعتمدها دون مقارنة إعداد النشر الفعلي.
- أنشئت Dockerfile وأدوات التشغيل والاختبار. تعذر بناء Docker محلياً لعدم توفره؛ تم تضمين فحص الصورة في CI ولا يُسجل نجاحه قبل قراءة النتيجة.
