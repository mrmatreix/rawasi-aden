# تصميم المطبوعات والتقارير — 2026-10-25

المسار: إعدادات النظام ← تصميم المطبوعات والتقارير.

1. ابحث عن المستند واختره من دليل 41 عملية، ثم عدّل عنوانه.
2. افتح مجموعات الهوية أو المحتوى أو التواقيع أو إعدادات الورقة. تظهر التعديلات مباشرة في معاينة A4.
3. اختر نمط رسمي أو مبسط أو اقتصادي؛ لا يُحفظ الاختيار تلقائيًا. يظهر تنبيه التعديلات غير المحفوظة.
4. كبّر الورقة أو استخدم ملاءمة العرض. تتيح قائمة الصفحات الانتقال بين أوراق المعاينة الطويلة، مع تقسيم صفوف الجداول وتكرار رأس الجدول.
5. استخدم بيانات توضيحية، أو اختر سند قبض/صرف محفوظًا. المصدر ظاهر بوضوح؛ القراءة تتبع صلاحيات واجهات النظام. بقية المستندات تعرض نماذج توضيحية.
6. حفظ وتطبيق يحفظ الإعدادات العامة. حفظ كقالب جديد يفتح حقل الاسم ثم يحفظ القالب عند إدخاله والضغط مجددًا أو استخدام زر حفظ القالب.
7. طباعة تجريبية / PDF تفتح نفس محتوى الأوراق بالتكبير الطبيعي؛ اختر حفظ PDF من نافذة المتصفح.

التحقق: نجحت الاختبارات الآلية الـ56 على قاعدة مؤقتة. اختبار متصفح مستقل تحقق من الدليل والمجموعات والعنوان الفوري وحالة الحفظ وعرض سند محفوظ بقيمة صفر وصور عرض مكتبي وهاتف. لا تعدّل المعاينة السندات المالية. الجداول العريضة والكتل المفردة التي يتجاوز ارتفاعها ورقة كاملة تحتاج اختيار الاتجاه الأفقي أو خط أصغر؛ قد يعيد المتصفح تقسيم تلك الكتل عند الطباعة.
